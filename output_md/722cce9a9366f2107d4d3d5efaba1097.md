# Issue: ASM DATA Disk Group Space Exhausted

**Issue Category:** Other

**Description:**
The ASM DATA disk group has run out of space, which may affect the performance and availability of the associated services.

**Steps to Resolve:**
- Log into the ServiceNow instance.
- Navigate to the incident management module.
- Search for the incident number INC0010012.
- Review the incident details and confirm the issue.
- Check the current disk usage on the ASM DATA disk group.
- Identify any unnecessary files or backups that can be deleted.
- Increase the disk space allocation for the ASM DATA disk group if possible.
- Notify the relevant stakeholders about the disk space issue.
- Monitor the disk space usage after the resolution steps.
- Document the resolution steps taken in the incident record.

**Technical Details:**
The ASM DATA disk group is currently at full capacity, which can lead to service disruptions. Logs indicate that no additional data can be written to the disk group. The affected systems include the database services relying on this disk group.
